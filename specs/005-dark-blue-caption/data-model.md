# Phase 1 データモデル: タイトルバーを濃い青にする

**Feature**: 005-dark-blue-caption
**Date**: 2026-09-09
**前提**: 001〜004 の data-model.md を基準とし、本書はその**差分のみ**を定義する。

---

## 1. 新設するエンティティ: なし

本フィーチャーは**状態を一切持たない**。ウィンドウが作られるときに色を1回渡すだけであり、保持・更新・参照される値が存在しない。

既存の構造（`TargetFolderState`・`SetupStep`・`StepResult`・`GitState`・`AnchorMode`・`AnchorEntry`）は**一切変更しない**。

## 2. 追加するメンバ変数: なし

`CMFCApplication1Dlg` にメンバは増えない。004 で追加した `m_anchors`・`m_initialClientSize`・`m_minWindowSize`・`m_layoutReady` もそのままとする。

**Rationale**: 「着色に成功したか」を覚えておく必要が無い。成功しても失敗しても後続の処理は同じであり（FR-408）、その値を読む場所がどこにも無い。持たせれば必ず「使われないメンバ」になる（憲章 原則III のYAGNI）。

R-407 のとおり DWM が色を保持するため、「今の色」をアプリ側で持つ必要も無い。

---

## 3. 追加する定数

実装ファイル内のファイルスコープ定数として2つだけ置く。

| 定数 | 値 | 意味 |
|---|---|---|
| キャプション背景色 | `0x0064381F` | ネイビー `#1F3864`（FR-402） |
| キャプション文字色 | `0x00FFFFFF` | 白（FR-403） |

**COLORREF は `0x00BBGGRR` の順**であり、`#RRGGBB` とは逆である（[research.md](./research.md) R-402）。`#1F3864` を素直に `0x001F3864` と書くと R と B が入れ替わって茶色寄りの色になるため、**この2つの定数には必ず由来を示すコメントを添える**。

`RGB(0x1F, 0x38, 0x64)` マクロを使えば並べ替えを間違えないが、リテラルで書く場合は上記のとおり `0x0064381F` となる。どちらで書くかは実装時に選んでよい。**マクロを使うほうが取り違えを構造的に防げるため推奨する**。

---

## 4. 状態遷移

**なし**。設定は初期化時の1回限りで、以後変化しない。

| 出来事 | 色に対する処理 |
|---|---|
| ダイアログの初期化 | 2つの属性を設定する（これのみ） |
| サイズ変更・最大化・最小化・復帰 | **何もしない**（DWM が保持する。R-407） |
| アクティブ／非アクティブの切り替え | **何もしない**（同じ色のまま。R-408） |
| ライトモード／ダークモードの切り替え | **何もしない**（明示指定が優先される） |
| 5手順の実行中・完了後 | **何もしない**（着色と処理は無関係） |

この表の「何もしない」は、実装漏れではなく**設計上の決定**である。再設定の処理を足すと 004 の `OnSize` に無関係な責務が混ざる。
