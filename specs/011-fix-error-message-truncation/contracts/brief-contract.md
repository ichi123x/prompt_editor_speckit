# Contract: `Brief()` の振る舞い契約

**Feature**: [../spec.md](../spec.md) | **Date**: 2026-09-13

`Brief()`は`SetupRunner.cpp`内の5箇所の失敗分岐（`RunInstallUv`・`RunInstallSpecify`・
`RunInitSpecKit`・`RunInitGit`）が共有する、外部コマンドの出力を結果一覧の理由欄向けに整形する
唯一の窓口である。本書は、本フィーチャーで**変えない部分**と**変える部分**を明示する。

## シグネチャ（変更なし）

```cpp
CString Brief(const CString& output, int maxLength = 160);
```

引数・戻り値の型、既定の`maxLength`は変更しない。既存の全呼び出し元は無修正のまま動作する。

## 事前条件（Preconditions、変更なし）

- `output`は外部コマンドの標準出力・標準エラーを結合した文字列（空でもよい）

## 事後条件（Postconditions）— 太字が本フィーチャーで新たに保証する内容

1. `output`が空の場合: 空文字列を返す（既存と同じ）
2. `output`を装飾除去した結果、内容行が1つの段落にまとまり、かつその長さが`maxLength`以下の場合:
   その段落をそのまま返す（既存と同じ。装飾も空行も無い短い出力は変化しない — SC-1102）
3. **`output`を行分割し、各行から装飾文字（Box Drawing・Block Elements）を除去したうえで、
   空行1行は区切りとみなさず2行以上連続した空行でのみ区切って段落にまとめたとき、戻り値には
   最後の段落の先頭`maxLength`文字が含まれる**（FR-1101・FR-1102）。先行する段落（バナー・
   進行状況・無関係な情報ボックス等）の内容は戻り値から除外される
4. **内容行が1つも無かった場合（出力全体が装飾のみだった場合）、戻り値は装飾除去前の正規化済み
   テキストを先頭から`maxLength`文字に切り詰めたものになる**（FR-1103、既存動作へのフォールバック）
5. 戻り値の長さは、省略記号を含めても既存の`maxLength + 3`文字程度を超えない（FR-1104、006の
   列幅制約との整合を維持）

## 呼び出し元が守るべき前提（不変）

- `SetupRunner.cpp`の5箇所の失敗分岐は、`Brief()`の戻り値を`Finish()`の理由文字列としてそのまま
  使うのみであり、本フィーチャーによってこれらの呼び出し元コードは変更されない（FR-1105）
- `ProcessRunner::Run()`が返す`ProcessResult.output`の意味・取得方法（008・009の成果）は本フィーチャー
  によって一切変更されない
