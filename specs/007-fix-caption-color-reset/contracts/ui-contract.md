# UIコントラクト: フォルダ選択ダイアログ後もタイトルバーの色を保つ

**Feature**: 007-fix-caption-color-reset
**Date**: 2026-09-12
**前提**: 005 の ui-contract.md を基準とし、本書はその**差分のみ**を定義する。記載のない契約は 005・006 のまま有効。

静的テスト ST-701〜703 と動的テスト DT-701 は本書を基準に実施する。

---

## 1. コントロールの構成（変更なし）

006 完了時点のコントロール構成・配置・リサイズ追従・列幅比率を**一切変更しない**。本フィーチャーが触るのは、フォルダ選択ダイアログを閉じた直後のタイトルバーの色のみである。

---

## 2. 再適用の契約（追加）

| 契機 | 処理 | 根拠 |
|---|---|---|
| `OnInitDialog`（起動時） | `ApplyCaptionColor()` を1回呼ぶ | 005 FR-404（継承） |
| `CFolderPickerDialog::DoModal()` を呼ぶ直前 | `ApplyCaptionColor()` を1回呼ぶ | FR-701（新規） |
| `CFolderPickerDialog::DoModal()` が返った直後 | `ApplyCaptionColor()` を1回呼ぶ | FR-701, FR-702（新規） |
| 上記3箇所以外のすべての場所 | **呼ばない** | 005 FR-405〜407（継承）、FR-704 |

**契約**:

- `DoModal()` を呼ぶ**直前**にも再適用する。これは、ダイアログを**開いた瞬間**に色が既定色へ戻る可能性（利用者の実機報告、spec.md User Story 1 Acceptance Scenario 1）に備えるためであり、「閉じた後にだけ直せばよい」という前提を置かない
- `DoModal()` の**戻り値を問わず**、返った直後にも再適用する。`IDOK`（選択）でも、それ以外（キャンセル・×ボタン）でも同じ処理を行う（FR-701 のシナリオ2・3に対応）
- 返った直後の再適用は `dialog.DoModal() != IDOK` による早期 return の**前**に行う。早期 return の後に置くと、キャンセル時に実行されない
- 再適用の呼び出しは `OnBnClickedButtonBrowse` 内の**2箇所（直前・直後）のみ**とする。`OnActivate` や `WM_NCACTIVATE` など、フォルダ選択ダイアログ以外の要因でも発火する汎用的な契機は使わない（005 FR-411 の趣旨を継承し、対象範囲を広げない）
- 色の値・並び（`0x00BBGGRR`）は 005 からの継承であり、本フィーチャーでは変更しない

---

## 3. 着色できない環境での契約（継承・変更なし）

005 の契約（戻り値を判定しない、成否を記録する変数を持たない、着色できない環境ではキャプションが既定の外観になるだけで他は同一の動作）を**そのまま継承**する。`ApplyCaptionColor()` の呼び出し元が増えても、この契約は変わらない（FR-703）。

**検証は新設しない**。005で検証済みの `DwmSetWindowAttribute` 呼び出しを新しい呼び出し箇所へ複製するだけであり、新しいコードパスや新しい失敗モードを持ち込まない。したがって、[quickstart.md](./../quickstart.md) の ST-702（戻り値を判定していないことの確認）が、呼び出し箇所が3つに増えた状態でも同じ性質を保証し、FR-703 の検証を兼ねる。005 の DT-409 のような模擬テストを追加するのは、この規模の変更に対しては過剰と判断する（憲章 原則III のYAGNI）。

---

## 4. 着色の対象範囲の契約（継承・変更なし）

| ウィンドウ | 着色するか | 根拠 |
|---|---|---|
| メインダイアログ | **する** | 005 FR-401（継承） |
| メッセージボックス | しない | 005 FR-411（継承） |
| フォルダ選択ダイアログ自体 | しない | 005 FR-411（継承）。本フィーチャーが直すのはメインダイアログの色であり、フォルダ選択ダイアログ自身の見た目には触れない |
| バージョン情報ダイアログ | しない | 005 FR-411（継承） |

---

## 5. 検証方法の契約（継承・一部追加）

005 の契約（採取位置は右端から200・上端から15、期待値は `#1F3864` との完全一致）を継承する。

**追加の契約**:

- フォルダ選択ダイアログの開閉を伴う検証は、**利用者による手動実行**とする（[research.md](./../research.md) R-704）。自動化されたスクリプトによる開閉操作では不具合を再現できなかったため、「修正前は再現し修正後はしない」ことを自動で示すことはできない
- 手動確認の際は、ウィンドウの右端から200・上端から15の位置を採取するか、目視で「他のアプリと見分けがつく濃さの紺色」であることを確認する

---

## 6. 既存機能への影響（**変更してはならないもの**）

005 の該当表を継承する。追加で、以下を明記する。

| 機能 | 根拠 |
|---|---|
| フォルダ選択ダイアログの見た目・操作（開く位置、フォルダツリーの操作、キャンセル・選択の動作） | FR-704 |
| 「参照...」ボタン押下後にパス表示欄へ選択結果を反映する処理（`OnBnClickedButtonBrowse` の既存ロジック） | FR-704。`ApplyCaptionColor()` の呼び出しを追加するのみで、既存の分岐・代入は変更しない |

**特に、`dialog.DoModal() != IDOK` の分岐の中身（コメントを含む）は変更しない。** 変更するのは `CFolderPickerDialog dialog(...)` の直後（`DoModal()` を呼ぶ直前）に1行、`DoModal()` の戻り値を受けた直後・早期 return の前に1行、の計2行を追加することのみである。
