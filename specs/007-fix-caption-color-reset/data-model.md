# Phase 1 データモデル: フォルダ選択ダイアログ後もタイトルバーの色を保つ

**Feature**: 007-fix-caption-color-reset
**Date**: 2026-09-12
**前提**: 005 の data-model.md を基準とし、本書はその**差分のみ**を定義する。

---

## 1. 新設するエンティティ: なし

005 と同様、本フィーチャーは**状態を一切持たない**。フォルダ選択ダイアログが閉じたという出来事をきっかけに、既存の2つの色定数を再度渡すだけであり、保持・更新・参照される値は増えない。

## 2. 追加するメンバ変数: なし

`CMFCApplication1Dlg` に**メンバ変数は増えない**。追加するのは非公開メンバ**関数** `ApplyCaptionColor()` の1つのみで、これは引数も戻り値も持たず、内部状態も参照しない。

**Rationale**: 「フォルダ選択ダイアログを閉じた回数」や「前回の色」を覚えておく必要が無い。呼ぶたびに同じ2つの定数を渡すだけであり、記録すべき値が無い（憲章 原則III のYAGNI）。

## 3. 追加する非公開メンバ関数

| 関数 | シグネチャ | 内容 |
|---|---|---|
| `ApplyCaptionColor` | `void ApplyCaptionColor()` | 005 の2定数（ネイビー・白）を使い `DwmSetWindowAttribute` を2回呼ぶ。戻り値は判定しない（FR-703 / 005 FR-408 を継承） |

**呼び出し元**（3箇所、いずれも `MFCApplication1Dlg.cpp` 内）:

1. `OnInitDialog`（既存の2行をこの関数呼び出しに置き換える）
2. `OnBnClickedButtonBrowse`（`CFolderPickerDialog::DoModal()` を呼ぶ**直前**、新規）
3. `OnBnClickedButtonBrowse`（同じく `DoModal()` が**返った直後**、戻り値を問わず、新規）

2と3の両方を呼ぶのは、利用者の報告どおりダイアログを**開いた瞬間**に色が崩れる可能性と、**閉じた後**に崩れたままになる可能性の両方に備えるためである（FR-701, spec.md User Story 1 Acceptance Scenario 1）。

## 4. 状態遷移

005 の表に、フォルダ選択ダイアログの開閉という1行を追加する。

| 出来事 | 色に対する処理 |
|---|---|
| ダイアログの初期化 | `ApplyCaptionColor()` を呼ぶ（005 から変更なし、呼び方のみ関数化） |
| サイズ変更・最大化・最小化・復帰 | **何もしない**（005 のまま。DWM が保持する） |
| アクティブ／非アクティブの切り替え | **何もしない**（005 のまま） |
| ライトモード／ダークモードの切り替え | **何もしない**（005 のまま） |
| **フォルダ選択ダイアログを開く直前（新規）** | **`ApplyCaptionColor()` を呼ぶ**（FR-701） |
| **フォルダ選択ダイアログが閉じた直後（新規）** | **`ApplyCaptionColor()` を呼ぶ**（FR-701, FR-702） |
| 5手順の実行中・完了後 | **何もしない**（005 のまま） |

「フォルダ選択ダイアログを開閉する」の2行以外が「何もしない」のは実装漏れではなく、005 からの設計上の決定を継承したものである。この2行にだけ再適用の処理を足す。
