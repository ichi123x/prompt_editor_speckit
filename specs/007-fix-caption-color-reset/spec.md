# Feature Specification: フォルダ選択ダイアログ後もタイトルバーの色を保つ

**Feature Branch**: `007-fix-caption-color-reset`

**Created**: 2026-09-12

**Status**: Draft

**Input**: User description: "参照ボタンを押してフォルダ選択ダイアログ（CFolderPickerDialog）を開くと、メインダイアログのタイトルバーの色が濃紺(#1F3864)から白（既定色）に変わってしまう。フォルダを選択して閉じても、キャンセルして閉じても、タイトルバーの色は白いままで濃紺に戻らない。005で実装した「タイトルバーの色は OnInitDialog で1回設定すれば非アクティブ・最大化・最小化からの復帰・ライト/ダークモード切替のいずれでも保たれる」という前提が、フォルダ選択ダイアログを開いた場合には成立しないことが実機で判明した。メインダイアログのタイトルバーは、フォルダ選択ダイアログを開いて閉じた後も含め、常に濃紺のまま保たれるべきである。"

## 005 との関係

本フィーチャーは 005（タイトルバーを濃い青にする）で見落とされていた不具合の修正である。005 は「非アクティブ・最大化・最小化からの復帰・ライト/ダークモード切替」では色が保たれることを実機で確認していたが（005 research.md R-407, R-408）、**「参照」ボタンでフォルダ選択ダイアログ（`CFolderPickerDialog`）を開いて閉じる」という状態遷移は検証されていなかった。実機ではこの遷移でタイトルバーが既定色（白）に戻り、二度と濃紺に復帰しないことが判明した。

| 既存の要件 | 本フィーチャーでの扱い |
|---|---|
| 005 FR-401〜FR-404, FR-407, FR-409〜FR-412（色・文字色・初期適用タイミング・ダークモード対応・失敗時の扱い・対象範囲・トレーサビリティ） | 変更しない |
| 005 FR-405, FR-406（非アクティブ・最大化・最小化・復帰で色を保つ） | 置き換えない。**追加として**、フォルダ選択ダイアログの表示・終了という遷移でも色を保つことを要求する（本仕様 FR-701） |
| 005 FR-408（着色できない環境では何も起こらない） | 変更しない |
| 001〜004 の要件 | 変更しない |

## User Scenarios & Testing（ユーザーシナリオとテスト） *(必須)*

### User Story 1 - フォルダを選んでもツールのウィンドウを見失わない (Priority: P1)

利用者は「参照...」ボタンでフォルダ選択ダイアログを開き、対象フォルダを選ぶ。ダイアログを閉じてメインダイアログに戻ったとき、タイトルバーが濃紺のままであれば、複数のウィンドウが並ぶ画面の中でも引き続き色だけでこのツールを見分けられる。現状はここで色が白（既定色）に抜けてしまい、005 が実現した「色で見分けられる」という価値が、フォルダを選んだ直後から失われている。

**Why this priority（この優先度である理由）**: 「参照」はこのツールの主要な操作であり、ほぼ毎回の利用で通る経路。ここで色が抜けると、005 の効果がアプリ起動直後の一瞬しか持続しないことになり、フィーチャーの目的を実質的に無効化する。

**Independent Test（独立したテスト方法）**: アプリを起動し、「参照...」ボタンを押してフォルダ選択ダイアログを開き、フォルダを選んで「フォルダーの選択」を押す。メインダイアログに戻った直後にタイトルバーの色を確認する。

**Acceptance Scenarios（受け入れシナリオ）**:

1. **Given** 起動直後で濃紺のタイトルバー、**When** 「参照...」を押してフォルダ選択ダイアログを開く、**Then** メインダイアログのタイトルバーは（フォルダ選択ダイアログの陰に隠れているとしても）濃紺のままである
2. **Given** フォルダ選択ダイアログが開いている、**When** フォルダを選んで「フォルダーの選択」を押す、**Then** メインダイアログに戻った直後、タイトルバーは濃紺のままである
3. **Given** フォルダ選択ダイアログが開いている、**When** 「キャンセル」を押す、またはダイアログを閉じる、**Then** メインダイアログに戻った直後、タイトルバーは濃紺のままである
4. **Given** 参照ボタンを何度も押してフォルダ選択ダイアログの開閉を繰り返した状態、**When** タイトルバーを見る、**Then** 何度繰り返しても濃紺のままである

---

### Edge Cases（エッジケース）

- **フォルダ選択ダイアログを開いたまま、他のアプリのウィンドウをクリックしてメインダイアログ全体を非アクティブにしたとき**: フォルダ選択ダイアログを閉じてメインダイアログに戻れば、タイトルバーは濃紺でなければならない
- **フォルダ選択ダイアログを開いてから、Alt+Tab などでメインダイアログとフォルダ選択ダイアログの間を行き来したとき**: 最終的にフォルダ選択ダイアログを閉じた後、タイトルバーは濃紺でなければならない
- **着色できない環境（Windows 10 など）でフォルダ選択ダイアログを開閉したとき**: 005 FR-408 のとおり、元々着色されていないので何も起こらない。エラーや警告を出してはならない

## Requirements（要件） *(必須)*

### Functional Requirements（機能要件）

- **FR-701**: メインダイアログのタイトルバーは、フォルダ選択ダイアログを**開いている間も含めて常に**、005 FR-402 の濃紺 `#1F3864` のままでなければならない（開く前、開いている間、フォルダを選択して閉じた後、キャンセルして閉じた後のすべてを含む）
- **FR-702**: FR-701 の色の保持は、フォルダ選択ダイアログの開閉を何度繰り返しても成立しなければならない
- **FR-703**: 着色できない環境（005 FR-408 が適用される環境）では、本フィーチャーの修正によって新たな警告・エラー・ログを出してはならない。元々着色されていない場合は、そのまま何も起こらない
- **FR-704**: 本修正は、フォルダ選択ダイアログの見た目・動作（開く位置、選択操作、キャンセル操作）を変更してはならない。修正の対象はメインダイアログのタイトルバーのみとする
- **FR-705**: 005〜006 で確立した他の要件（ダイアログのサイズ・コントロールの構成・配置・リサイズ追従・結果一覧・案内欄の内容）は一切変更してはならない
- **FR-706**: 追加・変更した各箇所には、対応する FR 番号をコメントで記載しなければならない（憲章 原則IV）

## Success Criteria（成功基準） *(必須)*

### Measurable Outcomes（測定可能な成果）

- **SC-701**: 「参照...」ボタンでフォルダ選択ダイアログを開いて閉じる操作を10回連続で行っても、タイトルバーは常に濃紺のままである（フォルダを選ぶ場合・キャンセルする場合の両方を含む）
- **SC-702**: 修正後、005 の合格項目（SC-401〜SC-405）がすべて再現する
- **SC-703**: ビルド警告が0件で、コード分析の指摘が0件

## Assumptions（前提事項）

- **原因は非クライアント領域の再描画である**。フォルダ選択ダイアログ（`CFolderPickerDialog`、内部的には Vista スタイルの `IFileDialog`）を開閉する過程で、メインダイアログに対して非クライアント領域の再描画を促すメッセージ（テーマ変更やアクティブ状態の変化など）が送られ、DWM が保持していたはずのキャプション色が既定色に戻ると推測される。005 の実機確認（非アクティブ・最大化・最小化・復帰）ではこの経路を通らなかったため見落とされていた
- **対象は Windows 11 のみ**。005 の前提を引き継ぎ、着色できない環境（Windows 10 など）での挙動確認は不要とする
- **色の再設定で解決する**。DWM に一度設定した色を保持させ続ける方法が無い場合、フォルダ選択ダイアログを**開く直前**と**閉じた直後**の両方で色を再設定する対応を許容する。これは 005 が禁じた「`OnSize` などでの塗り直し」とは異なる契機（フォルダ選択ダイアログの表示・終了）であり、005 FR-405〜407 の意図（色を安定して保つ）に反しない
