# Feature Specification: 生成されるCLAUDE.mdの日本語化

**Feature Branch**: `014-japanese-claude-md`

**Created**: 2026-09-13

**Status**: Implemented

**Input**: User description: "013で自動化した手順6（CLAUDE.md の生成とコミット）が生成するCLAUDE.mdの本文が英語になる。UI・コメント・ドキュメントをすべて日本語で統一する本アプリの方針に合わせ、日本語で生成されるようにする。"

**013との関係**: 013は`claude --print /init --permission-mode bypassPermissions --output-format text`というコマンドラインでCLAUDE.mdの生成を自動化した（FR-1304）。生成される言語は`claude`自身の既定の判断に委ねていたため、実機では英語になった。本フィーチャーはこのコマンドラインに日本語指示を1点加えるのみで、013が定めたそれ以外の挙動（存在確認によるスキップ、生成確認、コミット方法、依存関係、失敗時の扱い）はすべて維持する。

## User Scenarios & Testing（ユーザーシナリオとテスト） *(必須)*

### User Story 1 - 生成されるCLAUDE.mdが日本語で書かれている (Priority: P1)

利用者が「生成」を実行すると、手順6が自動生成するCLAUDE.mdの本文（見出し・説明文）が日本語で書かれている。本アプリ自体のUI・コメント・完了案内がすべて日本語であることと一貫しており、利用者が読んですぐ理解できる。

**Why this priority（この優先度である理由）**: 本アプリは「日本語での一貫性」を憲章の原則として掲げている。自動生成した成果物だけが英語のままでは、利用者（特に英語を主要言語としない開発者）にとって使いにくく、他の日本語ドキュメント（本アプリ自身のCLAUDE.md等）との一貫性も崩れる。

**Independent Test（独立したテスト方法）**: CLAUDE.mdが存在しない対象フォルダで「生成」を実行し、生成されたCLAUDE.mdの本文（定型ヘッダー2行を除く）が日本語で書かれていることを確認する。

**Acceptance Scenarios（受け入れシナリオ）**:

1. **Given** CLAUDE.mdが存在しない対象フォルダ、**When** 「生成」を実行して手順6が成功する、**Then** 生成されたCLAUDE.mdの本文（プロジェクト概要・ビルド方法等の説明文・見出し）が日本語で書かれている
2. **Given** 生成されたCLAUDE.md、**When** 内容を確認する、**Then** `claude`自身が常に付与する定型ヘッダー2行（`# CLAUDE.md`、`This file provides guidance to Claude Code...`）は英語のままでもよい（この2行は本フィーチャーの対象外）
3. **Given** 手順6が生成・コミットまで成功する、**When** 013で定義した他の挙動（既存CLAUDE.mdがあればスキップ、生成確認、`git add -- CLAUDE.md`によるコミット、`InitGit`への依存、失敗時の扱い）を確認する、**Then** いずれも013から変更されていない

---

### Edge Cases（エッジケース）

- 対象フォルダの既存コード・コメントが英語ばかりの場合、日本語指示を付けても`claude`が要約対象の固有名詞（クラス名、関数名等）まで無理に翻訳してしまうか? → 実機検証では、コード識別子はそのまま（英語）で保持され、説明文のみが日本語になった。無理な翻訳は本フィーチャーの要求ではなく、`claude`の判断に委ねる
- 日本語指示を付けても`claude`が英語で応答した場合はどうなるか? → 013の既存の成功判定（終了コード0 かつ CLAUDE.md存在）はそのまま使う。本フィーチャーは生成される文書の言語を保証する新しい検証手段を追加しない（Assumptions参照）

## Requirements（要件） *(必須)*

### Functional Requirements（機能要件）

- **FR-1401**: システムは、手順6が`/init`を実行する際のプロンプトに、CLAUDE.mdを日本語で書くよう指示する文言を含めなければならない
- **FR-1402**: 上記以外の手順6の挙動（CLAUDE.md存在確認によるスキップ、`--permission-mode bypassPermissions`・`--output-format text`等の既存フラグ、生成確認、`git add -- CLAUDE.md`によるステージングとコミット、`InitGit`への依存、失敗時の扱い）は013から一切変更してはならない
- **FR-1403**: 本フィーチャーは`RunGenerateClaudeMd`のコマンドライン文字列1箇所の変更に閉じ、`SetupRunner.h`・`ProcessRunner.*`・`MFCApplication1Dlg.cpp`・`.rc`には変更を加えてはならない

## Success Criteria（成功基準） *(必須)*

### Measurable Outcomes（測定可能な成果）

- **SC-1401**: 「生成」を実行して手順6が成功したとき、生成されたCLAUDE.mdの本文（定型ヘッダー2行を除く）が日本語で書かれている
- **SC-1402**: 013で合格していた検証項目（ST-1301〜1303、手順6のべき等性・単体コミット・依存関係）がすべて再現する

## Assumptions（前提事項）

- CLAUDE.mdが日本語で書かれているかどうかを機械的（文字コード判定等）に自動検証する仕組みは導入しない。判定は目視確認（実機検証・DTタスク）に委ねる。これは、日本語指示を付けても`claude`の生成内容そのものの言語を100%機械的に保証する簡便な方法がない（自然言語の応答であり、固有名詞や引用符が英語のまま残るのは正常）ためである
- コード内の識別子（クラス名・関数名等）が英語のまま説明文に引用されることは許容する。翻訳の対象は説明文・見出しであり、識別子ではない
- `claude`自身が付与する定型ヘッダー2行（`# CLAUDE.md`、`This file provides guidance...`）が英語のままであることは許容する。この2行はプロンプトの指示によらず`claude`が固定で付与するものであり、013の実機検証・本フィーチャーの実機検証の両方で確認済みである
