# Data Model: 導入処理の実行中はダイアログを閉じられないようにする

**Feature**: 018-block-close-while-running
**Date**: 2026-11-02

本フィーチャーは新しいデータ構造を追加しない。既存の2つの要素について、本フィーチャーで定める扱いを記す。

---

## 1. 実行状態（`CMFCApplication1Dlg::m_running`、既存）

| 項目 | 内容 |
|---|---|
| 型 | `bool`（変更しない。research.md R-1803） |
| 読み書きするスレッド | UI スレッドのみ |
| 既存の用途 | 001 FR-014（二重実行防止） |
| 018 で追加する用途 | FR-1801・FR-1804（閉じる操作を受け付けるかの判定） |

### 状態遷移

```text
            「生成」押下・検証合格               WM_APP_SETUP_COMPLETED 受信
 [待機中] ───────────────────────────▶ [実行中] ─────────────────────────────▶ [待機中]
 m_running = false                     m_running = true                       m_running = false
 閉じる操作 → 閉じる (FR-1804)         閉じる操作 → 案内のみ (FR-1801・1802)
                                       処理は継続 (FR-1803)
       ▲
       │ スレッド起動失敗時は即座に戻す（既存）
```

- 検証（フォルダ未選択・書き込み権限・マーカー等）で中止した場合は `[待機中]` から動かない
  （spec User Story 2 シナリオ3）。
- `[実行中]` → `[待機中]` の遷移は、手順の成功・失敗・途中の中止に関わらず必ず起きる（既存の
  `OnSetupCompletedMessage` の契約）。

---

## 2. 手順の結果の通知（`SetupStep` のコピー、既存）

ワーカースレッドが各手順の完了時に、その手順の `SetupStep` をコピーしてダイアログへ送る。

### 所有権の移り変わり（FR-1806・FR-1807、憲章 O-3）

```text
 ワーカースレッド (OnStepFinished)                       UI スレッド (OnStepFinishedMessage)
 ┌──────────────────────────────────┐                    ┌──────────────────────────────────┐
 │ 1. make_unique でコピーを作る     │                    │ 4. lParam を直ちに unique_ptr で   │
 │    所有者: 送る側の unique_ptr    │                    │    受け取り直す                    │
 │ 2. PostMessage(..., ptr)          │ ── メッセージ ──▶ │    所有者: 受ける側の unique_ptr    │
 │ 3a. 成功 → release()              │                    │ 5. 一覧に表示する                  │
 │     所有者: メッセージ（O-1例外）  │                    │ 6. 関数を抜けると自動で解放        │
 │ 3b. 失敗 → 何もしない             │                    └──────────────────────────────────┘
 │     関数を抜けると自動で解放       │
 └──────────────────────────────────┘
```

| 時点 | 所有者 | 解放の責任 |
|---|---|---|
| 1〜2 | 送る側の `unique_ptr` | `unique_ptr`（自動） |
| 3a〜4 の間 | メッセージキュー上のメッセージ（生ポインタ） | 受ける側（O-1 の例外。コードにコメントで明記） |
| 3b | 送る側の `unique_ptr` | `unique_ptr`（自動、FR-1806） |
| 4〜6 | 受ける側の `unique_ptr` | `unique_ptr`（自動、FR-1807） |
