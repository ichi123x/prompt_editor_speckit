# UIコントラクト: 導入処理の実行中はダイアログを閉じられないようにする

**Feature**: 018-block-close-while-running
**Date**: 2026-11-02
**前提**: 001〜017のui-contract.mdを基準とし、本書はその**差分のみ**を定義する。記載のない契約は017のまま有効。

---

## 1. コントロールの構成

変更しない。コントロールの追加・削除・座標変更・有効/無効の切り替え規則の変更はいずれも行わない。
実行中に無効化するコントロールは、従来どおり「生成」「参照...」のみであり（016 のラジオボタンは 016 FR-1608
の改訂により無効化しない）、
「OK」「キャンセル」は実行中も**有効なまま**とする（research.md R-1801）。

---

## 2. 閉じる操作の契約

**契約（FR-1801・FR-1802・FR-1803・FR-1804）**:

| 閉じる操作 | 待機中（`m_running == false`） | 実行中（`m_running == true`） |
|---|---|---|
| 「OK」ボタン / Enter キー | ダイアログを閉じる（従来どおり） | 閉じない。案内を表示する |
| 「キャンセル」ボタン / Esc キー | ダイアログを閉じる（従来どおり） | 閉じない。案内を表示する |
| タイトルバーの ✖ / Alt+F4 / システムメニューの「閉じる」/ タスクバーの「ウィンドウを閉じる」 | ダイアログを閉じる（従来どおり） | 閉じない。案内を表示する |

- 「待機中」は、起動直後・導入処理の完了後（成功・失敗・途中の中止のいずれも）・検証による中止後を含む。
- 実行中に閉じる操作を受け付けなかった場合も、導入処理は中断しない。結果一覧への追加と完了案内の表示は
  従来どおり行われる。

---

## 3. 案内の契約

**契約（FR-1802）**:

| 項目 | 値 |
|---|---|
| 表示方法 | メッセージボックス（モーダル） |
| 文言 | 「導入処理の実行中は閉じられません。完了までお待ちください。」 |
| ボタン | 「OK」のみ |
| アイコン | 情報（i） |

- 案内を閉じた後、ダイアログは表示されたまま操作可能な状態に戻る。
- 実行中に閉じる操作を繰り返した場合は、そのたびに同じ案内を表示する（回数の制限や文言の変化は無い）。
